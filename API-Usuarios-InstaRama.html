Autenticación JWT

Authorization: Bearer <token> En progreso

Se está implementando la autenticación con JWT. Todavía no está en main: hoy todos los endpoints responden sin token (SecurityConfig deja pasar todo con permitAll()). Esta sección explica lo que va a cambiar para que el frontend esté listo. Los detalles pueden ajustarse cuando se integre.

Mientras tanto Sigan usando la API como está documentada abajo. Cuando JWT llegue a main, esta sección se actualizará con los endpoints y respuestas reales.

Qué va a cambiar

HoyCon JWT
POST /api/users/login regresa el UserRegresará un token (y probablemente los datos básicos del usuario)
Cualquier petición funciona sin tokenCasi todas pedirán el header Authorization: Bearer <token>
—Registro e inicio de sesión seguirán siendo públicos
Sin token no hay errorSin token, o con uno vencido o inválido, la API responderá 401
Comentarios piden ?userId= en la URLEl usuario se podrá sacar del token, así que ese parámetro podría desaparecer

Ejemplo de petición con token

GET /api/users/1 HTTP/1.1
Host: localhost:8080
Content-Type: application/json
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxIn0.firma

Cómo prepararse en el frontend

  1. Hagan todas las llamadas a la API desde una sola función (por ejemplo en assets/js/utils.js), así después solo hay que agregar el header en un lugar.
  2. Al hacer login, guarden lo que regrese la API en un solo lugar (por ejemplo localStorage) para poder cambiarlo por el token sin tocar cada página.
  3. Preparen qué hacer con un 401: borrar la sesión y mandar al usuario a login.html.
const API = "http://localhost:8080/api";

export async function api(ruta, opciones = {}) {
  const token = localStorage.getItem("token"); // null mientras no haya JWT
  const resp = await fetch(API + ruta, {
    ...opciones,
    headers: {
      "Content-Type": "application/json",
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
      ...opciones.headers,
    },
  });
  if (resp.status === 401) {
    localStorage.removeItem("token");
    location.href = "login.html";
  }
  return resp;
}

Mientras no haya JWT, token es null y la función manda las peticiones igual que hoy, así que pueden empezar a usarla desde ya.
